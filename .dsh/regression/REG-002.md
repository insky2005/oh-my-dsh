# REG-002 「无证据不进设计」规划门禁

长期不变量：`stage ∈ {design, task, acceptance, delivery}` 的事项卡必须带**规划四件套证据**——
目标（WHAT）/ 边界 / 验收标准（可机检）/ 阶段裁剪声明；判据见
`docs/design/panels/planning-template-design.md` §2 与 §4。

- **边界（P2）**：只查**存在性**（写法自由，可用「（做）/（不做）」两栏或平铺一条）；
  是否覆盖做/不做由人 Review。

- `stage=planning` 不检查（尚未进设计）；
- 缺任一 → 该卡失败（exit≠0），并指明缺失项；
- 门要能自证（架构原则 9）：用缺证据样例可复现 FAIL；
- 后事项打破门 → **后事项失败**，不重开来源事项（原则 14）。

运行：

```sh
node .dsh/regression/check-planning-gate.mjs
```

> 判据只来自规划模板设计，不在此另立标准；模板变更时本门随之更新。
